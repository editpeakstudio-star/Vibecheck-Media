## About

Vibecheck-Media is a modern web project focused on a clean interface, responsive design, and a smooth user experience.

Built with modern frontend technologies and deployed using Firebase Hosting.

## Features

- Modern and clean user interface
- Responsive, mobile-friendly design
- Optimized production build
- Fast development with Vite
- Firebase Hosting deployment

## Tech Stack

- React
- Vite
- JavaScript / TypeScript
- CSS
- Firebase Hosting
- npm

## Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Vibecheck-Media-
```

Install dependencies:

```bash
npm install
```

## Development

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

The production files are generated in the `dist/` directory.

## Firebase Deployment

```bash
firebase deploy --only hosting --project vibecheck-media
```
